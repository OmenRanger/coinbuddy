# CoinBuddy Roadmap

## MVP (launch)
- Mobile-first PWA
- Local-first storage (IndexedDB)
- Home dashboard with 5 primary actions
- Add coin manually (simple form)
- Scan coin (photo upload/capture front/back + manual confirm)
- Collection list (search, sort, filter)
- Coin detail (edit, delete w/ confirm, favorite, needs review)
- Value estimator (manual comparables  low/mid/high + confidence)
- Archive & Reports (export JSON + CSV; printable report view)
- Learn (static articles)
- Auctions (saved sources + add link)
- Tests + build pipeline
- README + release checklist

## V1.1 (quality & comfort)
- Better image handling: thumbnails, compression tuning
- Draft autosave improvements
- Extra-large text mode
- More guided empty states
- Import validation + conflict handling

## V1.2 (archive & insurance)
- Insurance packet PDF export (selected coins + photos)
- Receipt/certificate attachments
- Better report templates

## V2 (optional cloud backup)
- Opt-in Supabase backup/sync
- Multi-device restore

## V3 (market discovery)
- Permitted integrations: APIs/RSS feeds with attribution
- Price history + alerts (only if sources are reliable)
