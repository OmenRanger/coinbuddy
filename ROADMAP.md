# CoinBuddy Roadmap

## Phase 1: Local-First MVP

- Build the warm mobile-first app shell.
- Add manual coin entry and scanner-style image upload.
- Support inventory search, sort, edit, delete, favorites, and needs-review flags.
- Add manual comparable sale entry and transparent value range calculation.
- Add archive exports and printable collection summary.
- Add education and auctions/source pages.
- Add tests, build scripts, and product documentation.

## Phase 2: Better Capture And Reports

- Add guided camera capture with image cropping.
- Add PDF report generation.
- Add receipt/document attachments.
- Add richer value history charts.
- Add import conflict handling and backup reminders.

## Phase 3: Cloud Sync

- Add Supabase auth, database, and storage.
- Keep public anon keys client-side only.
- Add migration scripts and row-level security policies.
- Preserve local export/import for user control.

## Phase 4: Market And Learning Integrations

- Add permitted official APIs, RSS feeds, or affiliate feeds.
- Add source attribution and date stamping for all estimates.
- Add optional professional appraisal contact workflow.
- Add curated learning paths for beginner collectors.

## Phase 5: Family And Estate Planning

- Add shared read-only family access.
- Add estate-ready collection packet exports.
- Add insurance-prep checklist status.
- Add secure cloud backup health checks.
