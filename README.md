# CoinBuddy

CoinBuddy is a warm, mother-friendly coin collection app: photograph coins, track your inventory, keep proof-of-ownership records, and create transparent value estimate ranges with exportable reports.

Primary audience: a non-technical collector (Micahs mother).

## MVP features (target)
- Scan/upload coin photos (front/back) with manual confirmation
- Add coins manually
- Collection list with search/sort/filter
- Coin detail view with edit/delete (confirmation)
- Value estimator using comparable sales (manual input)
- Archive & Reports: export JSON + CSV; printable report view
- Learn: starter educational articles (static)
- Auctions: curated/saved sources + manual links

## What CoinBuddy is not
- Not a professional appraisal tool
- Not a guarantee of insurance coverage
- Not legal/financial advice

Value estimates are **estimated market ranges** based on inputs and sources you provide. For high-value coins, consider a professional appraisal.
