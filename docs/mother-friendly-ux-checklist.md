# Mother-Friendly UX Checklist

Use this checklist before each release.

## Home

- The five main actions are visible without hunting.
- The labels are plain: Scan Coin, Add Coin Manually, My Collection, Value Estimate, Archive & Reports.
- The app explains issues gently, especially missing photos or needs-review records.

## Add And Scan

- A coin can be added without using camera features.
- Image upload has a manual fallback.
- Required fields are minimal.
- Helper text appears near fields that may be confusing.
- Saving shows a success message.

## Collection

- Search is easy to find.
- Sort and filter controls use plain labels.
- Empty states tell the user what to do next.
- Coin cards show the most useful details first.

## Detail

- Photos, year, denomination, country, location, and value range are easy to scan.
- Edit and delete are clear.
- Delete requires confirmation.
- Value wording says estimate, not appraisal.

## Archive And Reports

- JSON and CSV exports are available.
- The report page includes an insurance-prep note.
- The app does not imply coverage is guaranteed.

## Accessibility

- Text remains readable on mobile and desktop.
- Tap targets are large.
- Forms have visible labels.
- Focus states are visible.
- Color is not the only signal.
- No important action is icon-only.
