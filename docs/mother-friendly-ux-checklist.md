# Mother-Friendly UX Checklist (CoinBuddy)

Use this checklist for every screen and workflow.

## Navigation & clarity
- [ ] Home screen shows 5 primary actions as large buttons:
  - Scan Coin
  - Add Coin Manually
  - My Collection
  - Value Estimate
  - Archive & Reports
- [ ] Each primary action is reachable in 1 tap from Home.
- [ ] Labels are plain language (no developer jargon).
- [ ] No essential feature is buried 3+ screens deep.

## Tap targets & readability
- [ ] Buttons are large and comfortably tappable.
- [ ] Body text is readable on a phone without zoom.
- [ ] High-contrast text on backgrounds.
- [ ] No icon-only buttons for important actions (icons may accompany text).

## Forms (Add/Edit Coin)
- [ ] Field labels match how a collector thinks (e.g., Year, Mint mark).
- [ ] Helper text appears under confusing fields (mint mark, composition, grading).
- [ ] Required fields are minimal.
- [ ] Save is obvious and always visible.
- [ ] After save, show a clear success message.
- [ ] Drafts are preserved where practical (avoid losing work).

## Photo capture/upload
- [ ] Obverse vs reverse is explained with a simple note.
- [ ] User can skip photos and add later.
- [ ] If photo upload fails, error message says what to do next.

## Errors & confirmations
- [ ] Errors are human-readable and suggest next steps.
- [ ] Destructive actions (delete) require confirmation.
- [ ] Undo or Cancel is available wherever reasonable.

## Empty states
- [ ] Empty collection shows a friendly prompt + buttons:
  - Scan Coin, Add Coin Manually
- [ ] Empty export/reports shows what exports are for.
- [ ] Auctions page explains its a curated list and can be expanded later.

## Value estimate messaging (safety)
- [ ] Always show Estimated market range wording.
- [ ] Show date, confidence level, and sources.
- [ ] Clearly state: not an official appraisal.

## Accessibility
- [ ] Keyboard accessible forms and buttons.
- [ ] Visible focus states.
- [ ] Screen-reader friendly labels (no placeholder-only labels).
- [ ] No important information conveyed only by color.
- [ ] Motion is minimal; no distracting animations.

## Mom test manual QA
- [ ] She opens the app and immediately knows what to press.
- [ ] She can add a coin without instructions.
- [ ] She can find the coin later.
- [ ] She understands the value estimate is a range and not guaranteed.
- [ ] She can export her records.
- [ ] No screen feels overwhelming.
