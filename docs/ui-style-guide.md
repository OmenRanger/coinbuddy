# CoinBuddy UI Style Guide

Chosen direction: **Vintage Americana Collectors Ledger**

## Design goals
- Warm, trustworthy, premium-but-simple
- Feels like a collectors ledger / archive card catalog
- Not tacky, not cluttered, not overly dark
- Mobile-first, older-user friendly

## Palette (initial)
- Background: Parchment / cream
- Primary ink: Deep navy
- Accent: Antique gold / brass
- Secondary: Oxblood / warm brown
- Borders: warm gray / sepia

(Exact tokens will be implemented as CSS variables so themes are consistent.)

## Typography
- Headings: a classic serif with modern readability (ledger feel)
- Body: clean sans-serif for clarity
- Avoid tiny text. Prefer 16px+ base.

## Components
- Cards: rounded, subtle shadow, thin sepia border
- Buttons: large, text-first labels; icon optional
- Inputs: clear labels above fields; helper text below
- Dividers: subtle ledger lines

## Layout rules
- Home: 5 big primary actions, plus a small summary card
- Keep screens focused: one main job per page
- Avoid dense tables; prefer cards and grouped sections

## Iconography
- Simple, friendly, not overly decorative
- Never rely on icons alone for meaning

## Motion
- Minimal. Prefer subtle transitions only.
- Avoid distracting animations.

## Content tone
- Friendly, calm, and confidence-building
- Use Estimated market range language
- Clear disclaimers where needed
