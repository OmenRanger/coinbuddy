# UI Style Guide

## Explored Directions

### Vintage Americana Ledger

Cream paper, deep navy, oxblood, brass accents, ledger dividers, warm coin imagery, and modern mobile-first layout.

### Premium Coin Vault

Darker navy, museum-like surfaces, stronger gold accents, and a secure archive feeling.

### Friendly Collector Notebook

Soft paper tones, large cards, notebook spacing, simple language, and the most approachable mood.

## Chosen Direction

CoinBuddy uses Vintage Americana Ledger with the friendliness of Collector Notebook. It should feel like an old coin shop met a clean personal archive: warm, trustworthy, practical, and calm.

## Palette

- Parchment: `#f7edd8`
- Ledger cream: `#fffaf0`
- Deep navy: `#17324d`
- Oxblood: `#8b2f2d`
- Brass: `#b98a36`
- Ink: `#2c241b`
- Sage success: `#4d6b50`

## Typography

Use system fonts for reliability. Headings can feel slightly formal through weight, spacing, and color rather than decorative typefaces.

## Layout

- Mobile-first.
- Large tap targets.
- Clear routes and stable controls.
- Cards are for repeated coin/source/article items or focused tools.
- Avoid nested cards.
- Keep screens calm and scannable.

## Wording

Use:

- Add Coin to My Collection
- Estimate confidence
- Estimated market range
- Needs review
- Archive & Reports

Avoid:

- Inventory object
- Appraisal certainty
- Technical storage jargon
- Hidden destructive actions
