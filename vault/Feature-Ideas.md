# Feature Ideas (Backlog)

This file is intentionally a backlog. MVP items should stay in docs/product-brief.md and the in-app UI.

## Scanning & identification (post-MVP)
- Assisted identification: suggest possible matches from user-entered hints + curated reference links.
- Photo guidance overlay: Center coin, Use good light, Avoid glare.
- Cropping + rotate tools.
- Background removal (optional) to improve clarity.
- Side-by-side obverse/reverse compare view.

## Collection organization
- Custom folders/collections (e.g., Pennies, Grandpas Coins).
- Smart groups (Needs review, Missing photos, High value).
- Batch edit (tags, storage location).

## Value & market data
- Add permitted data sources (APIs/RSS) with explicit source attribution.
- Price history chart per coin (manual entries first).
- Alerts: Value changed significantly (only if reliable sources exist).

## Archive & insurance exports
- Insurance packet export (PDF): selected coins + photos + totals.
- Estate planning export template.
- Attach receipts/certificates (files) to coins.

## Education
- Short, friendly lessons (23 minutes each).
- What is a mint mark? helper popovers.
- Fraud/scam awareness checklist.

## Auctions / discovery
- User-curated source list with categories:
  - Auctions
  - Dealers
  - Reference pricing
  - News
- Per-source notes (I trust this one).
- Watchlist that stores links + personal notes.

## Backup & sync
- Optional cloud backup (Supabase) with clear opt-in.
- Export reminder nudge (gentle, not annoying).

## Accessibility & comfort
- Extra-large text mode.
- Simple mode that hides advanced fields.
