# CoinBuddy Context

CoinBuddy is a standalone app for a simple, trustworthy coin collection workflow. It should feel like a gift for a mother: warm, useful, and easy to navigate.

Core promise:

- Add coins with photos.
- Keep inventory records.
- Estimate possible market range from comparable sales.
- Export archive records.
- Learn safe storage and documentation basics.

Tone:

- Vintage Americana ledger
- Calm
- Clear
- Premium but not showy
- Practical over clever

Boundaries:

- No official grading claims.
- No official appraisal claims.
- No insurance coverage promises.
- No third-party scraping that violates terms.
