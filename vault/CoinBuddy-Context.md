# CoinBuddy Context

## Why this exists
CoinBuddy is a gift-quality, mother-friendly coin collection app. It should feel safe, simple, and trustworthy while still supporting real collector needs: photos, inventory, archival proof, value ranges, education, and exportable records.

## Primary user
Micahs mother.

Key needs:
- Simple home screen with obvious next actions
- Forgiving data entry
- Clear confirmations and success feedback
- Easy export for insurance/estate documentation

## Product principles
- Local-first MVP
- Exportable + durable records
- Minimal settings
- Transparent value estimation (range + sources + confidence)
- No overconfident identification/grading claims

## Design direction
Vintage Americana Collectors Ledger:
- cream paper background
- deep navy headings
- brass/gold accents
- card layouts, not tables
- calm, minimal, premium

## MVP definition of done
- Add coin (manual) + optional photos
- Collection list + search/sort/filter
- Coin detail edit/delete
- Value estimator with comparables
- Archive & Reports exports JSON/CSV
- Learn + Auctions starter content
- Tests pass; build passes

## Notes / constraints
- No scraping in violation of terms.
- No legal/financial advice; use general guidance language.
- Keep repo standalone and clean.
